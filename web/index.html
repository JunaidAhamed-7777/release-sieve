Your text stays in this browser.

The first run downloads about 38 MB of open model and runtime files from this site. Cached assets are reused when browser storage is available. Drafts are not stored.

The model is intended for English prose. It reads only the first 256 wordpieces of each message or note; any truncation is reported. Keep evidence concise. Combined text and paths are limited to 500,000 characters; uploaded files must be smaller than 2 MB.

Review policy & model limits

Cosine similarity measures related meaning, not confidence or correctness. Internal commit types are a heuristic; breaking changes always need review. Close-scoring notes show the runner-up for comparison.
